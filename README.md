# upside-down-room
Игра + Редактор уровней, где можно менять гравитацию у персонажа и перемещаться по стенам, потолку - любым плоскостям), Перемещайтесь по комнатам, уворачивайтесь от красных зон, открывайте двери и находите выход из комнаты - все это в "Комнате вверх дном". P.S. Запускается в браузере одним html файлом (+ во втором файле редактор уровней)
